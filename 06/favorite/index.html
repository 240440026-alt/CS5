好きな数学の定理

作成日: 2026年10月21日

大数の弱法則

定理

　確率空間 \( (\Omega, \mathcal{F}, P) \) 上の独立確率変数列 \( X_1, X_2, \dots, X_n, \dots \) が, 平均 \( \mu \), 分散 \( \sigma \)をもつ
同一分布に従うとする. \( S_n := X_1 + X_2 + \dots + X_n \), \( n = 1, 2, \dots \) とおく.
このとき, 任意の \( \epsilon > 0 \)に対して, \[\displaystyle P \left( \left| \frac{S_n}{n} - \mu \right| \ge \epsilon \right) \to 0 \quad (n \to \infty) \]
が成り立つ.

証明

\( E[X_n] = \mu, V[X_n] = \sigma^2 \ (n = 1, 2, \dots) \) であるから, \[\displaystyle E\left[\frac{S_n}{n}\right] = \frac{1}{n} \sum_{k=1}^{n} E[X_k] = \mu \] \( \{X_n\}_{n=1}^\infty \perp\!\!\!\perp \) ゆえ, 独立な確率変数の分散の性質
\[ V[aX] = a^2 V[X] , V[X+Y] = V[X] + V[Y] \]より, \[\displaystyle V\left[\frac{S_n}{n}\right] = \frac{1}{n^2} \sum_{k=1}^{n} V[X_k] = \frac{\sigma^2}{n} \] 従って, チェビシェフの不等式
\[ P(|X - E[X]| \ge \epsilon) \le \frac{V[X]}{\epsilon^2} \] より, \[\displaystyle P\left(\left|\frac{S_n}{n} - \mu\right| \ge \epsilon\right) = P\left(\left|\frac{S_n}{n} - E\left[\frac{S_n}{n}\right]\right| \ge \epsilon\right) \le \frac{V\left[\frac{S_n}{n}\right]}{\epsilon^2} = \frac{\sigma^2}{n\epsilon^2} \to 0 \quad (n \to \infty) \]
が成り立つ. \(\square\)

※独立な確率変数の分散の性質, チェビシェフの不等式の証明は省略することにする.

身近な例えの例

排出率1%でピックアップのキャラが排出されるガチャがあるとする.
このとき, 1万回, 10万回と引く回数を増やしていけば, 実際の排出率が『1%』から大きくズレる確率はほぼ0に近づく.

注意

上の例において, 大数の弱法則ではたまたま運悪く, 何千回も連続で当たらない暗黒期が一瞬だけ訪れる可能性を
理論上完全に排除することはできない.

大数の強法則

定理

　確率空間 \( (\Omega, \mathcal{F}, P) \) 上の独立確率変数列 \( X_1, X_2, \dots, X_n, \dots \) が、平均 \( \mu \), 分散 \( \sigma \)をもつ
同一分布に従うとする. \( S_n := X_1 + X_2 + \dots + X_n \), \( n = 1, 2, \dots \) とおく. このとき,
\[\displaystyle P \left( \lim_{n \to \infty} \frac{S_n}{n} = \mu \right) = 1 \quad \text{即ち}, \quad \frac{S_n}{n} \to \mu \quad \text{a.e.} \]
が成り立つ.

証明

\( Y_k := X_k - \mu \quad (k = 1, 2, \dots) \) とし, \( \widetilde{S}_n = S_n - n\mu \) とおくと, \[ \widetilde{S}_n = \sum_{k=1}^{n} Y_k \quad (n = 1, 2, \dots) \] さらに, \( T(n) = \max\{|\widetilde{S}_1|, |\widetilde{S}_2|, \dots, |\widetilde{S}_n|\} \quad (n = 1, 2, \dots) \) とおくと, コルモゴロフ（Kolmogorov）の不等式 \[ P\left( \max_{1 \le k \le n} \left| \sum_{i=1}^k Y_i \right| \ge \epsilon \right) \le \frac{1}{\epsilon^2} \sum_{i=1}^n V[Y_i] \] より, 任意の \( \epsilon > 0 \) に対して, \[ P(T(n) \ge \epsilon) \le \frac{1}{\epsilon^2} \sum_{k=1}^{n} V[Y_k] = \frac{1}{\epsilon^2} \sum_{k=1}^{n} V[X_k] = \frac{n\sigma^2}{\epsilon^2} \quad (n = 1, 2, \dots) \] \( n = 8^k, \epsilon = 4^k \quad (k = 1, 2, \dots) \) とおいて, \[ P(T(8^k) \ge 4^k) \le \frac{8^k \sigma^2}{4^{2k}} = \frac{\sigma^2}{2^k} \quad (k = 1, 2, \dots) \] 即ち, \[ P\left( \frac{T(8^k)}{8^k} \ge \frac{1}{2^k} \right) \le \frac{\sigma^2}{2^k} \quad (k = 1, 2, \dots) \] 従って, \[ \sum_{k=1}^{\infty} P\left( \frac{T(8^k)}{8^k} \ge \frac{1}{2^k} \right) \le \sigma^2 \sum_{k=1}^{\infty} \left( \frac{1}{2} \right)^k = \sigma^2 < \infty \] となり, ボレル・カンテルリ（Borel-Cantelli）の定理 \[ \sum_{k=1}^\infty P(A_k) < \infty \Rightarrow P(\varliminf_{k\to\infty} A_k^c)=1 \]より, \[ P\left( \varliminf_{k\to\infty} \left\{ \omega \ ; \ \frac{T_\omega(8^k)}{8^k} \le \frac{1}{2^k} \right\} \right)=1 \] が成り立つ. これは, \[ \lim_{k\to\infty} \frac{T(8^k)}{8^k}=0 \quad (P-\text{a.e.}) \] を意味する. 任意の \( n \) に対して, \( 8^{k-1} \le n < 8^k \) なる \( k=k(n) \) をとれば, \( n \to \infty \) のとき \( k \to \infty \) であるから, \[ \left| \frac{\widetilde{S}_n}{n} \right| \le \frac{T(8^k)}{8^{k-1}}=8 \frac{T(8^k)}{8^k} \to 0 \quad (P-\text{a.e.}) \] となり結論を得る. \(\square\)

※ボレル・カンテルリ（Borel-Cantelli）の定理, コルモゴロフ（Kolmogorov）の不等式の証明は省略することにする.

身近な例えの例

排出率1%でピックアップのキャラが排出されるガチャがあるとする.
ガチャを無限に引き続けるという世界線において, 排出率は最終的に『1%』という数字に完全に張り付く.
そうならない例外的な世界線の確率は『完全に0』である.

大数の弱法則との比較

上の例において, 大数の強法則では弱法則が残していた弱みが打ち消され,
「確率は絶対に1%に収束し, 例外は存在しない」と断言できる.
